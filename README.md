The official web portal of the **Agradhi Media Unit**, developed to facilitate media unit submissions, user management, and administrative activities.

## About

The Agradhi Media Unit Portal is the official digital platform of our school's Media Unit.

The system provides a centralized platform for authorized users to submit required information and for administrators to monitor and manage submissions through an administrative dashboard.

## Features

### User Portal

* User registration and authentication
* Secure user login
* User dashboard
* Submission forms
* Submission of required information
* Access to submitted information

### Administration Portal

* Administrative authentication
* Administrator dashboard
* Monitoring of user submissions
* Reviewing submitted information
* Managing submitted records
* Centralized administration of the portal

## Progressive Web App

The portal is configured as a Progressive Web App (PWA), allowing supported browsers and devices to install and launch it as an application.

The portal is deployed and hosted using Netlify.

The deployment status badge at the top of this README automatically reflects the current status of the latest production deployment.

## Access

The portal is intended for authorized members and administrators of the school's Media Unit.

Administrative functionality is restricted to authorized administrators.

## Purpose

The primary purpose of this portal is to provide a centralized digital platform for the school's Media Unit.

It is designed to simplify submission processes, improve administrative management, and provide a structured system for handling Media Unit records.

## Security

Authentication and access control are implemented to restrict administrative functionality to authorized users.

## Maintenance

The portal is maintained as an official school Media Unit system. Changes to administrative functionality, authentication, submissions, or stored data should be made only by authorized developers or administrators.
